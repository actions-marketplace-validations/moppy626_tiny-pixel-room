fonts/unifont_jp-subset-18.0.01.otf is a subset of GNU Unifont JP 18.0.01
(unifont_jp-18.0.01.otf, the Japanese version of GNU Unifont;
https://unifoundry.com/unifont/ , https://ftp.gnu.org/gnu/unifont/unifont-18.0.01/).
Only the characters that Tiny Pixel Room draws are kept (see scripts/subset-unifont.mjs).
No glyphs were changed. The license description and license URL in the font's
name table (name IDs 13 and 14) were changed to the SIL Open Font License 1.1.
The settings site serves the same font as unifont_jp-subset-18.0.01.woff
(see scripts/build-site.mjs). The WOFF only compresses each table;
the font data is the same as in the OTF.
