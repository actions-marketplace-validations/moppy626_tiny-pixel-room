# セキュリティポリシー (Security Policy)

[日本語](#日本語) | [English](#english)

## 日本語

### 直す版

いちばん新しい `v1` の版を直します。古い版は直しません。

### 脆弱性の報告

脆弱性を見つけたときは、公開の Issue には書かず、[Report a vulnerability](https://github.com/moppy626/tiny-pixel-room/security/advisories/new) から非公開で知らせてください。報告はこのリポジトリの管理者だけが読めます。

次のことを書いてもらえると助かります。

- どんな問題か。悪用されると何ができてしまうか
- 再現する手順 (ワークフローの設定など)
- 問題がある版

報告を確かめて直したときは、新しい版を出して、修正の内容を公開します。

報告は日本語でも英語でもかまいません。

## English

### Supported versions

Fixes go into the latest `v1` release only. Older releases aren't fixed.

### Reporting a vulnerability

If you find a vulnerability, don't report it in a public issue. Report it privately via [Report a vulnerability](https://github.com/moppy626/tiny-pixel-room/security/advisories/new). Only the maintainers of this repository can read your report.

It helps if you include:

- What the problem is, and what someone could do by exploiting it
- Steps to reproduce it (such as your workflow settings)
- The affected versions

Once the report is confirmed and the problem is fixed, a new version is released and the details of the fix are published.

You can write your report in English or Japanese.
