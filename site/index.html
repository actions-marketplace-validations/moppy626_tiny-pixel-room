ドットのおへやTiny Pixel Room

GitHub で活動するほど育つ、ドット絵のおへやをプロフィールに飾れます。設定を選ぶとカードが変わり、下に貼り付けるコードができます。

Decorate your GitHub profile with a pixel-art room that grows as you stay active on GitHub. Pick your settings to update the card, then copy the code below.

設定Settings

キャラクターCharacter

あとで変えると、育て直しになります。

Changing it later starts the growth over.

10 文字まで。空のときは「カブ」になります。Up to 10 characters. If left empty, it will be "Turnip".

    カードの言葉Card language

    ページの上で選んだ言葉 (いまは日本語) になります。英語のカードにするときは、ページの上で English を選びます。

    It follows the language picked at the top of the page (English now). For a Japanese card, pick 日本語 at the top of the page.

    カードに出す項目Items on the card

    外した項目は詰めて並べます。すべて外すと、キャラクターだけの細いカードになります。

    Unchecked items are left out and the rest move up. Uncheck them all for a narrow card with just the character.

    背景Background

    自動にすると、見る人の GitHub やブラウザの設定に合わせて、昼と夜のおへやが切り替わります。昼か夜を選ぶと、いつもその背景になります。

    Auto switches between the day and night room to match each viewer's GitHub or browser setting. Pick Day or Night to always use that background.

    動きMotion

    動きを減らす設定にしている人には、動かないカードを見せます。

    Visitors who prefer reduced motion see a still card.

    プロフィールに飾るAdd it to your profile

    1. プロフィール用のリポジトリを用意するGet your profile repository ready

      ユーザー名と同じ名前の公開リポジトリです。まだなければ、GitHub で新しく作ります。

      This is the public repository with the same name as your username. If you don't have one yet, create it on GitHub.

    2. ワークフローを置くAdd the workflow

      そのリポジトリに .github/workflows/tiny-pixel-room.yml を作り、次の内容を貼ってコミットします。

      In that repository, create .github/workflows/tiny-pixel-room.yml, paste the following, and commit it.

      .github/workflows/tiny-pixel-room.yml

    3. カードができるのを待つWait for your card

      コミットすると Action が動き、1 分ほどで tiny-pixel-room フォルダにカードができます。そのあとは毎日 0:17 ごろ (日本時間) に更新されます。

      Once you commit, the Action runs and creates your card in the tiny-pixel-room folder in about a minute. After that, it updates every day around 15:17 UTC.

    4. README に貼るAdd it to your README

      プロフィール用のリポジトリの README.md に、次の内容を貼ります。

      Paste the following into the README.md of your profile repository.

      README.md

      カードの下には、このサイトへの小さなリンクが付きます。要らなければ、<br> からあとの 2 行を消してください。

      A small link to this site appears under the card. If you don't want it, delete the last two lines, starting from <br>.

    スターやコミットなどは、公開リポジトリの分だけを数えます。くわしくは README の「非公開の活動の扱い」にあります。

    Stars, commits, and the other stats count public repositories only. See the README's section on private activity.
